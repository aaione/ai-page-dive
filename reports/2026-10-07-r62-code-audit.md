## 被驳回发现（1）

- **「NM 单帧上限双源应单源化」**——证据行号属实（nm.ts:8 NM_MAX=1MB 与 sw.ts:670 NM_FRAME_MAX=1MB 确为两份字面量），但机制推演被证伪：sw.ts:671 门限实为 `> NM_FRAME_MAX - 64*1024`（960KB），协同靠「SW 门 < host 限」不等式+64KB 缓冲带，字面量相等从来不是协同条件；sw.ts:665-669 注释明示 1MB 是 Chrome 平台硬限的本地常量（有意决策，非契约漂移——r52 教训适用对象是 MAX_CHUNK 那种双侧须相等的包契约）；host 发送侧分片（stdio.ts:131/165）确为单源。**定性错误：有意的平台常量本地化 ≠ 契约漂移债。**
