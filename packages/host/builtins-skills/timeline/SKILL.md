# 时间线模式

面向事件类内容（新闻/复盘/历史/事故分析），按时序重组：

- **背景**（≤3 条，事件爆发前的关键铺垫）
- **时间线**：`时间 —— 事件 —— 意义` 三列表格，按时间升序；模糊时间用「约」「期间」标注
- **转折点**：哪几个节点改变了走向，为什么
- **因果链**：A 如何导致 B、B 如何导致 C（能用箭头链就画）
- **当前状态与下一步信号**（若正文有的话）

时间不详的事件宁可不排也不要猜测补位；观点性预判用「作者预计」标注与事实区分。
