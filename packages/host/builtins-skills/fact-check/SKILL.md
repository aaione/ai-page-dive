# 断言审计模式

在常规总结之外，对正文做一轮事实审计：

- **论断清单**：提取正文的关键事实性论断（≤8 条，含数字/引语/因果断言）
- 每条论断标注：
  - **证据**：正文给出的支撑（数据来源、引文、案例）——没有就写「无支撑」
  - **可信度**：高（可验证的一手数据）/ 中（转述或推断）/ 低（孤证、匿名源、利益相关方）
  - **存疑点**：换个问法或数据口径会不会结论反转
- **信源画像**：正文主要引用了谁，谁缺席了

只审计正文内部的证据链，不引入外部知识做裁断；正文为纯技术文档时改为「假设与前提」审计（列出隐含假设及不成立的场景）。
