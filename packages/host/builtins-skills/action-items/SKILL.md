# 行动清单模式

在常规总结之外，把正文转成可执行清单：

- **立即可做**（今天就能动手的，≤3 条，写清第一步动作）
- **值得研究**（需要先调研再决定的，注明要查什么）
- **持续关注**（趋势/风险类，写清触发再行动的条件）
- **明确不做**（正文诱惑很大但经分析应该放弃的，给出理由）

每条动作用「动词 + 对象 + 完成标准」写法，避免「了解一下」「关注一下」这类无法判断完成与否的表述。与己无关的正文则如实说明「无行动项」并一句话讲清判断依据。
